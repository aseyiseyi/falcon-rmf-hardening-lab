# FALCON: RMF Hardening Lab

## Scenario
FALCON is a fictional Air Force unit system made up of one Windows Server 2022 host and one Ubuntu 22.04 server. Acting as the system's ISSO, I harden, scan, assess, and package it for an Authorization to Operate using the DoD Risk Management Framework.

## What this project demonstrates
1. DISA STIG implementation and SCAP compliance scanning
2. Vulnerability management with Nessus, prioritized by CVSS, CISA KEV, and EPSS
3. RMF documentation: SSP, SAR, and POA&M mapped to NIST SP 800-53 Rev 5

## Lab environment
VirtualBox 7.2 on Windows 11, Windows Server 2022 Evaluation, Ubuntu Server 22.04.5 LTS
